POPPAD CAFÉ ORDER — DEMO BUILD v1
=================================
Fictional sales/demo café built from POPPAD ORDER MASTER v1.

INCLUDED
- Tablet-first customer ordering interface
- Coffee, Cold Drinks, Breakfast and Snacks
- Approved demo prices and customisations
- Multi-item basket
- Customer-name checkout
- Pay-at-counter wording
- Staff phone queue with 5-second auto-refresh
- COMPLETE ORDER action
- 90-second inactivity reset
- Apps Script backend with authoritative catalogue and server-side price recalculation

IMPORTANT
This ZIP is intentionally NOT connected to a live backend yet.
To activate live order sending:
1. Create a NEW Apps Script project for POPPAD CAFÉ.
2. Paste Code.gs and deploy as a web app.
3. Put the resulting /exec URL into config.js as orderApiUrl.
4. Deploy these web files to a separate demo repository/site.
5. Test full flow on actual customer tablet and staff phone.

ZOOPPLEMENTS is not referenced or modified by this package.
